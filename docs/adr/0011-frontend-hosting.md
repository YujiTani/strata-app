# ADR-0011: フロントエンドのホスティング

- ステータス: 決定
- 日付: 2026-07-14

## コンテキスト

Vite + Phaser（ADR-0009）でビルドしたフロントをどこに配信するか。バックエンド（Fly.io、ADR-0010）とは
別の観点（静的配信・CDN）で選ぶ必要があった。

## 決定

Cloudflare Pages を採用する。

## 理由

- ビルド後は静的ファイルになり、SSRは不要
- 画像・JSの配信量が多く、CDNが欲しい
- アセットサイズが制限内に収まる（超えてもR2に逃がせる）

## 結果・トレードオフ

- 得たもの: 静的配信・CDNの恩恵
- 実例: バックエンドとのCORS設定は実際には正しくできていたが、Pages側のキャッシュが効いていて
  正しいレスポンスが取得できていないように見えた、という切り分けに時間を使った
  （`docs/progress.md` 2026-07-14）
